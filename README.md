# Blok Kahramanı

Neon temalı 8x8 blok bulmaca oyunu. Parçaları sürükle, dolan satır ve sütunları patlat, kombo yap.
Kolay, Orta ve Zor seviye; her seviyenin rekoru ayrı tutulur.

**Oyna:** https://herophysio.github.io/blok-kahramani/

iPhone'da Safari'de açıp Paylaş → Ana Ekrana Ekle ile uygulama gibi tam ekran oynayabilirsin.
Oyunun tamamı tek dosya: `index.html` (HTML, CSS ve JavaScript).
